# 数据字典

适用 MySQL 8.0，InnoDB，UTF-8（utf8mb4）。全部业务时间使用 `DATETIME(6)`，Java 对应 `LocalDateTime`；应用和数据库会话按 Asia/Shanghai / `+08:00` 解释。无时区类型不可用于跨时区直接比较。

| 表 | 字段 | 类型 | 含义及默认值 |
|---|---|---|---|
| app_user | id | BIGINT PK 自增 | 用户标识 |
| app_user | student_no | VARCHAR(32) UNIQUE | 学号/账号标识 |
| app_user | name | VARCHAR(64) | 显示姓名 |
| app_user | password_hash | VARCHAR(255) | 由成员3接入的密码哈希；演示值明确禁用登录 |
| app_user | role | VARCHAR(32) | 默认 STUDENT，角色策略由成员3定义 |
| app_user | status | VARCHAR(32) | 默认 ACTIVE，账号状态策略由成员3定义 |
| seat | id | BIGINT PK 自增 | 座位标识 |
| seat | room / floor / seat_no | VARCHAR(64) / INT / VARCHAR(32) | 阅览室、楼层、室内座位号；三者组合唯一 |
| seat | status | VARCHAR(32) | 默认 AVAILABLE，座位状态策略由成员3定义 |
| slot | id | BIGINT PK 自增 | 固定时段标识 |
| slot | start_time / end_time | DATETIME(6) | 开始唯一，结束必须晚于开始，另有组合唯一键供预约外键使用 |
| reservation | id | BIGINT PK 自增 | 预约标识 |
| reservation | user_id / seat_id | BIGINT FK | 用户/座位标识 |
| reservation | slot_start / slot_end | DATETIME(6) FK | 引用同一条 slot；插入语句从 slot 获取结束时间 |
| reservation | status | VARCHAR(16) | RESERVED / CHECKED_IN / CANCELLED / EXPIRED / COMPLETED |
| reservation | check_in_deadline | DATETIME(6) | 上层传入的签到截止时间，完整签到策略由成员3处理 |
| reservation | version | INT | 乐观锁版本，初值 0 |
| reservation | active_seat_id / active_user_id | BIGINT 生成列，可空 | 活动状态复制 seat_id/user_id，其余状态 NULL；禁止手工写入 |
| credit | user_id | BIGINT PK FK | 每用户一条信用余额 |
| credit | score | INT | 初值 100，CHECK 约束为 0..100 |
| credit | restricted_until | DATETIME(6)，可空 | 限制截止时间，业务判定由成员3处理 |
| credit | version | INT | 乐观锁版本，初值 0 |
| credit_log | id | BIGINT PK 自增 | 信用流水标识 |
| credit_log | user_id / reservation_id | BIGINT FK | 所属用户和预约；事务组件校验预约归属 |
| credit_log | delta | INT | 有符号分值变动 |
| credit_log | reason | VARCHAR(64) | 原因码，与 reservation_id 组成幂等键；区分大小写 |
| credit_log | balance_after | INT | 本次变动后余额，0..100 |
| credit_log | created_at | DATETIME(6) | 默认 CURRENT_TIMESTAMP(6) |
| notification | id | BIGINT PK 自增 | 全局递增游标；用户可看到不连续 ID |
| notification | user_id | BIGINT FK | 收件用户，所有读取与标记操作必须带此字段 |
| notification | type / content | VARCHAR(32) / VARCHAR(1000) | 类型和消息正文 |
| notification | read_flag | BOOLEAN | 默认 false，仅允许 0/1 |
| notification | created_at | DATETIME(6) | 默认 CURRENT_TIMESTAMP(6) |

所有未标注可空的字段均 NOT NULL。外键不使用级联删除，避免删除用户或预约时悄悄丢失审计流水。Flyway 的 `flyway_schema_history` 是迁移元数据，不属于七张业务表。

`db/demo/V2__demo_data.sql` 仅供 demo 配置使用，默认生产迁移目录不含它。演示日期为首次执行时的次日，08/10/12/14/16/18/20 点开始，每段两小时；这是实施默认值，需交成员3确认时段规则。逾期示例遵循团队手册扣10分，余额90。演示用户的 `LOGIN_DISABLED_DEMO_ONLY` 不是密码哈希，不能作为登录实现。
