# SeatKeeper 成员4 数据与平台设计

范围：按照团队手册实现成员4的W1—W8。新项目位于当前目录，不覆盖原资料、学籍系统或队友代码。团队仓库为1572569562/SeatKeeper，成员4内容使用member4-data-platform分支提交，保留远程main历史。

技术：Java17、Maven3.9、Spring Boot3.5.14、MyBatis3.0.4、MySQL8.0、Flyway、HikariCP。全体代码注释中文、文本UTF-8，PowerShell脚本UTF-8 BOM。独立模板按个人规范建立分层软件包，采用单模块；正式工程沿用相同Java分层，并保留团队要求的seatkeeper-common、seatkeeper-service模块。

边界：实现数据源、迁移、7张业务表、数据库约束、Mapper、持久化事务组件及运维脚本；不实现成员3的完整登录/预约公共API和状态机，不实现JavaFX、守护节点、网关。不把数据组件测试冒充四机联调验收。Flyway自己的历史表不计入7张业务表。

表与数据约定：app_user(id,student_no,name,password_hash,role,status)、seat(id,room,floor,seat_no,status)、slot(id,start_time,end_time)、reservation(id,user_id,seat_id,slot_start,slot_end,status,check_in_deadline,version,active_seat_id,active_user_id)、credit(user_id,score,restricted_until,version)、credit_log(id,user_id,reservation_id,delta,reason,balance_after,created_at)、notification(id,user_id,type,content,read_flag,created_at)。统一DATETIME(6)，Asia/Shanghai，Java LocalDateTime；MySQL会话+08:00。

约束：活动状态RESERVED/CHECKED_IN通过生成列和唯一索引保护同座位/同用户/同时间段；reservation.slot_start外键引用slot.start_time。插入预约由INSERT SELECT获取slot_end，不能伪造区间。取消/过期后生成列为NULL允许重订。credit.score为0..100。credit_log的(reservation_id,reason)唯一，扣分锁住credit行，先查幂等记录再更新余额并插流水，事务原子；重放请求改变user/delta必须拒绝。必须核对预约所属用户。version比较更新，受影响行数为0表示冲突。通知分页与增量查询必须限制user_id，增量按id递增；清理只删已读且早于保留期，限制批量。

默认由实施者确定：演示7个时段为次日08/10/12/14/16/18/20点开始的2小时段，不宣称已由组长确认；时段长度/信用业务规则交成员3确认。只读健康检查和座位查询可用于本地验收，其他写入仅Java组件调用，无匿名写入API。

交付：独立springboot-template保留本地，团队仓库提交seatkeeper成员4工程；README有W1—W8清单、运行命令、已测/待联调区别；DDL说明、数据字典、Mapper交接、EXPLAIN记录、备份恢复与可重复演示重置脚本。重置仅接受固定项目库seatkeeper或严格以_test结尾的测试库，必须明确确认和库名校验；不删除其他库，不覆盖用户已有数据库。

验证：真实MySQL，不使用H2替代生成列/唯一索引。先写失败测试再实现。覆盖Flyway空库迁移与重启不重复、7业务表、7固定时段、取消后重订、200并发同座位1成功199冲突、同用户同槽冲突、乐观锁旧版本失败、信用100次重放只一条流水、越界余额回滚、通知用户隔离和游标、清理边界、备份恢复及两次重置数据一致。EXPLAIN验证可用索引，实际性能以测量记录为准。Docker如果无法启动，使用独立本机MySQL8.0验证，并明确Docker运行未验收。

方案取舍：采用MyBatis XML和数据库约束，方便成员3集成并符合手册；不引入Redis/MQ和额外架构。模板只含共享基础与可启动健康接口，成员4部分在完整工程中扩展。

审查后实施决定：Hikari显式READ_COMMITTED，信用仍使用主键行锁与幂等唯一键；通知先锁同用户credit行直到外层提交以保证游标不会跳过未提交低ID；测试清理在同一连接核验DATABASE()且严格匹配_test后缀。模板默认独立seatkeeper_template库，避免与正式V1迁移校验冲突。
